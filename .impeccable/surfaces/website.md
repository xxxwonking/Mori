# 宣传官网与组件文档

访客是评估和接入 uni-app x 组件库的开发者。首页为 Persuade，文档为 Read；沿用既有 Mori 世界。用户指定 Wot UI 官网和右侧手机模拟器作为结构参考。采用代码实现，不生成视觉稿。

## Direction contract

THESIS: 通过可操作的真实组件，让开发者在阅读前理解 Mori 的紧凑与一致性。

OWN-WORLD: 保留中性灰、清晰蓝、系统字体、三竖线标志和 36px 控件。页面层级由文字尺度和留白组织。

STORY: 首屏体验组件，按分类寻找组件，阅读源文档，复制 uni_modules 接入项目，查看准确的平台验证状态。

FIRST VIEWPORT: 顶部品牌、指南、组件与搜索；左侧短标题和接入入口，右侧真实 H5 预览及组件切换。文档采用左导航、中正文、右预览，窄屏将预览放入正文可展开区域。

FORM: 用户指定的成熟组件库官网结构；seed: none (brief-pinned)。签名交互是文档路由联动真实组件手机预览，支持主题、刷新、独立打开和二维码。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict pass, and the documenter.

不承诺 npm 发布或未取得的真机兼容性。二维码在本机地址下明确可访问范围；上线域名待用户提供。
