# 移动端接入与验收

Mori UI 优先面向手机，同时复用到 H5、微信小程序和 App。按钮／输入仍默认为 **36px**，控件文字 13px、标签 12px。小尺寸是既定视觉选择；页面应为相邻操作留出间距，避免把可点击范围缩成一个图标。

## 页面与安全区

- 使用自定义导航页时，为 Navbar 显式开启 `safe-area-inset-top`；使用系统导航栏时不要重复补偿顶部。
- Tabbar、ActionBar 与 Popup 默认处理底部安全区。外围页面已处理时，设置 `:safe-area-inset-bottom="false"`，避免双重留白。
- 固定 Navbar／Tabbar／ActionBar 不占布局空间，正文仍须预留组件实际高度及启用的安全区。不要同时显示系统 tabBar 和固定 Mori Tabbar。
- SafeArea 的 `size=-1` 为自动模式，H5 使用 CSS `env()`，微信与 App 读取 `uni.getWindowInfo().safeAreaInsets`，并在窗口变化后更新。`size>=0` 为显式 px 占位，不随窗口变化。
- H5 页面需保留 `viewport-fit=cover` 才能使用浏览器安全区；本项目入口已配置。侧边刘海、折叠屏铰链、系统导航栏／底部手势区域仍需在实际布局和设备上检查。

## 弹层与输入键盘

Popup 使用宿主 `scroll-view` 承载正文；长内容在正文内滚动，56px 标题行和 44px 关闭按钮保持可见。底部／居中／顶部弹层最大高度为可用窗口的 85%，并至少预留 40px 窗口余量；侧边弹层使用窗口高度。短内容保持自身高度。

H5 在未缩放页面时监听 `visualViewport` 的高度和偏移，响应浏览器工具栏或键盘引起的可视区变化；双指放大保留浏览器的缩放行为。微信／App 使用宿主窗口变化事件。并非所有系统键盘都会缩小窗口，原生键盘避让仍需结合宿主 `adjust-position`／页面滚动策略验证。

请把 Popup 及其组合组件放在页面根级，避开 transform／裁切祖先。H5 模态层管理背景滚动和焦点；小程序／原生页面背景滚动需按页面能力配置。没有跨端 teleport，不要依赖 Popup 内部 DOM 或私有类名修改滚动节点。

不通过 `user-scalable=no` 禁止浏览器缩放。iOS Safari 对小字号输入的聚焦缩放仍需要真机验收；保持用户选择的 13px 默认字号，不以放大整套控件掩盖问题。

## 窄屏与长内容

- Navbar 两侧操作各自限制宽度，长标题／操作文字单行省略；完整操作名仍作为可访问名称。关键正文不要放在导航标题里。
- Tabbar 标签保留单行并可省略，完整名称仍可被辅助技术读取；较多栏目宜使用可横向滚动的 Tabs，不要无限压缩底部导航。
- Checkbox／Radio 标签可换行，H5 的连续长字符串也不会撑宽选项；选择标记保持原尺寸。
- Table 的宽内容在组件内部横向滚动。VirtualList、List、IndexBar 等需要由页面给出合适的滚动窗口高度。
- Picker 等底部选择器的内容可以滚动；过长列表须检查末项及确认／取消可达性。不要隐藏关键功能来消除溢出。

## 可复现检查

```sh
npm run site:build
npm run site:preview
```

在另一个终端执行 `npm run test:mobile`。首次运行前安装浏览器：`npx playwright install chromium`。可用 `MORI_SITE_URL` 指向预览地址，用 `MORI_BROWSER_EXECUTABLE` 指定浏览器。

脚本巡检全部 88 个真实示例在 320px 的挂载与页面溢出，定向检查 320／390px 竖屏、844px 横屏的长内容弹层、触控关闭、长导航文字和打开期间的窗口变化。结果为 `.impeccable/review/mobile-verification.json`，截图为 `mobile-*.png`。`tests/viewport.mjs` 检查共享监听清理、安全区刷新与可视窗口事件，但使用的是接口替身。

## 设备验收清单

| 场景 | 需要检查 |
|---|---|
| iOS Safari／Android 浏览器 | 小字号输入聚焦、系统键盘、浏览器地址栏收放、双指缩放、页面回退 |
| 微信小程序 | AppID 与基础库版本、页面滚动锁、弹层内滚动、系统导航与胶囊区域 |
| iOS／Android App | 自定义导航、安全区、输入避让、横竖屏、前后台恢复、返回键 |
| 字体与可访问性 | 系统字体放大、屏幕阅读器、完整操作名、减少动态效果、仅键盘操作 |
| 内容与状态 | 长中英文、无数据、异步加载、禁用、错误、连续打开／关闭、嵌套弹层 |

记录真实设备／系统／编译器版本、复现步骤、截图和结论。浏览器模拟与微信编译结果不得填入真机通过栏，最新证据统一见 [兼容记录](compatibility.md) 和 [平台跟踪](platform-adaptation.md)。

当前 Chromium 底层触点注入的组合限制见 [测试说明](testing.md)：触摸点击与原始触点滚动分别验证，“滑动后立即点击关闭”保留为真机验收项。
