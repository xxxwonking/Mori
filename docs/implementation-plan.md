# 第一版实施计划

这是首版范围记录。下列六项在当前首版范围内已落实；原生真机与发布不在“已完成”的含义内。持续更新的状态和后续顺序以 [当前进度](progress.md) 为准，接手入口见 [agent 交接说明](agent-handoff.md)。

1. 初始化 uni-app x 根目录工程、uni_modules 组件目录和可复现的开发命令。
2. 建立统一颜色、尺寸、圆角和交互状态 token。
3. 实现 MoriButton、MoriInput、MoriSwitch、MoriCheckbox，并提供清楚的 API 和导入示例。
4. 搭建可交互工作台与手机表单预览，验证主题、加载、禁用、清空、密码、校验和重置。
5. 执行真实 H5 / 微信小程序编译、浏览器交互检查、桌面和手机截图检查；单独记录不能验证的原生平台。
6. 输出 README、组件说明、设计规范和兼容矩阵。

不发布 npm、插件市场或应用商店；不创建签名证书；所有实现留在桌面项目内。
